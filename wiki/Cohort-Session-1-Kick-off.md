# Session 1 · Kick-off

*Why does software with a model in it need a different lifecycle, and which of our projects is one?*

Part of the [Cohort Kit](Cohort-Kit). Ninety minutes. The session everything else stands on: by the
end the room has agreed on what the agentic PDLC changes, has one real candidate project on the
table, and has classified it, possibly as not an agent at all.

**Pre-reading** (send one week ahead; about 30 minutes)

- [What is the agentic PDLC?](https://akash-coded.github.io/aws-bedrock-agentcore-strands/learn/what-is-the-agentic-pdlc/) — the four phases, the one hard gate and the eight loops, in one sitting
- [How this tutorial works](https://akash-coded.github.io/aws-bedrock-agentcore-strands/learn/how-this-tutorial-works/) — so the cohort reads the same way
- [The evolution of the PDLC](https://akash-coded.github.io/aws-bedrock-agentcore-strands/learn/evolution-of-the-pdlc/) — what each earlier lifecycle fixed, and what this one has to
- [Why agentic AI projects fail](https://akash-coded.github.io/aws-bedrock-agentcore-strands/learn/why-agentic-ai-projects-fail/) — the six patterns, which the room will recognise

**Bring.** Every attendee brings **one candidate from the team's own backlog** that somebody has
called "an AI feature". A sentence each is enough. The session picks one.

**You will leave with.** A shared vocabulary, one candidate project the next seven sessions return
to, and an AI-fit verdict on it, written down.

## Facilitator notes

- **Most of a backlog is not AI.** Expect A1 to return "rule", "report" or "search" for more than half
  of what the room brought. Say so before the exercise so it reads as the lesson rather than as a
  verdict on somebody's idea. The team that learns this in session 1 saves a quarter.
- **The room will want to talk about models.** Redirect every "which model?" to the phase it belongs
  in (P1, next session). This session is about whether, not which.
- **Ten-minute version if nobody read:** the spine picture, the hard gate in one sentence ("nothing is
  built until the spec, the bar and the guardrails exist"), and the six failure patterns read aloud
  as a checklist against the candidates in the room.
- **Two candidates that tie** is fine: carry the one with the clearest damage figure, because session
  2 needs one.

## Homework

**The pain register** for the chosen candidate: the numbers behind the pain, in the product manager's
[Discover](https://akash-coded.github.io/aws-bedrock-agentcore-strands/templates/#lt-product-manager-discover)
and [Qualify](https://akash-coded.github.io/aws-bedrock-agentcore-strands/templates/#lt-product-manager-qualify)
templates. Cases per day, minutes per case, the cost of one wrong case. Estimates are fine; a blank
is not. Session 2 derives the bar from these.
